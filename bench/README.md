# bench: E1 benchmark (code alone, gold plans)

Implements E1 of [`docs/eval-plan.md`](../docs/eval-plan.md). Standard library only, Python 3.9+.
Written from the contract in [`plan-format.md`](../skills/receipts/references/plan-format.md) without reading the tool.

## Run

```sh
PYTHONUTF8=1 python bench/generate.py            # development seed 20261119 -> bench/out/20261119/
PYTHONUTF8=1 python bench/evaluate.py            # runs skills/receipts/scripts/receipts.py on it
```

Options: `--seed N`, `--out DIR` (both scripts); `--tool PATH`, `--results-dir DIR`, `--runs FILE`,
`--timeout SEC` (evaluate). The held-out seed `20261120` is refused unless `--held-out` is passed; per the
eval plan it is run once, on the release commit.

`evaluate.py` exits 0 when all eight bars pass, 1 when any fails, 2 when the tool or the generated data is missing.
A tool crash or invalid JSON on one document is recorded as a failure for that document; the run continues.

## Output

`bench/out/<seed>/` (gitignored, regenerated byte for byte from the seed):

- `manifest.json`: counts (by language, source type, formula, error type, number format) and the list of documents and abstention cases.
- `docs/<id>/report.md`: the document, one statement per line, plus distractors (dates, version, URL, headings, list markers, quarter label, a fenced code block).
- `docs/<id>/` sources: `*.csv`, `*.json`, `tables.md` or `book.xlsx` (1-2 files).
- `docs/<id>/claims.gold.json`: the gold plan. `claims.coverage.json`: the same with 10% of claims removed.
- `docs/<id>/gold.json`: per statement the line, `start`/`end` of the number token, text, language, formula, source type, planted error type (or null), `truncated_ok`, `removed_in_coverage`, truth and written values; plus every distractor with its expected skip rule.
- `abstain/<case>/`: `report.md`, source, `claims.json`, `expect.json` (`unverifiable` + `claim_id` for zero/multi-match locators, `exit2` for missing/corrupt sources).

Committed:

- `bench/results/<seed>-<commit>-<UTC>.json` and `.md`: measures, bars, breakdowns, unplaced tokens, distractor classification, failures.
- `bench/runs.jsonl`: one line per run (timestamp, seed, commit, dirty flag, counts, measures, pass per bar).
