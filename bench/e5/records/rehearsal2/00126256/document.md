# 삼성생명 2025년 사업보고서 메모

삼성생명의 2025년 사업보고서에 실린 재무제표 수치를 정리했다. 금액은 원화다.

- 2025년 12월 말의 연결 기준 자산총계는 350,685,701백만원으로 집계됐다.
- 연결 기준 영업활동으로부터의 현금흐름은 2025년 1월부터 12월까지 5,256,261백만원이었다.
- 별도 기준 당기순이익(손실)은 2025년 1월부터 12월까지 1조 6,998억원이었다.
- 연결 기준 2025년 1월부터 12월까지의 당기순이익(손실)은 한 해 전 같은 기간(2024년 1월부터 12월까지)보다 24.8% 줄었다.
- 연결 기준 2025년 1월부터 12월까지의 법인세비용은 5,448억원이다.
- 연결 기준 법인세비용차감전순이익은 2024년 1월부터 12월까지 1,821,290백만원이었다.
- 연결 기준 당기순이익(손실)은 2024년 1월부터 12월까지 2,260,255,000,000원이었다.
- 연결 기준 2025년 1월부터 12월까지의 법인세비용차감전순이익은 29,963억원이다.
- 연결 기준 2025년 1월부터 12월까지의 당기순이익(손실)은 1,983,439백만원이다.
- 2024년 12월 말의 연결 기준 부채총계는 274,116,162,000,000원으로 집계됐다.
- 연결 기준 2023년 1월부터 12월까지의 당기순이익(손실)은 2,260,255,000,000원이다.
- 연결 기준 2025년 12월 말의 부채비율(부채총계를 자본총계로 나눈 비율)은 440.9%이다.
