# 스퀘어텍 2025년 사업보고서 메모

스퀘어텍의 2025년 사업보고서에 실린 재무제표 수치를 정리했다. 금액은 원화다.

- 2025년 1월부터 12월까지의 연결 기준 수익(매출액)은 143억원으로 집계됐다.
- 연결 기준 2025년 1월부터 12월까지의 수익(매출액)은 한 해 전 같은 기간(2024년 1월부터 12월까지)보다 27.3% 늘었다.
- 연결 기준 2024년 1월부터 12월까지의 영업이익(손실)은 -27억원이다.
- 2024년 12월 말의 연결 기준 부채총계는 102억원으로 집계됐다.
- 연결 기준 수익(매출액)은 2023년 1월부터 12월까지 135억원이었다.
- 연결 기준 2024년 1월부터 12월까지의 수익(매출액)은 143억원이다.
- 연결 기준 자산총계는 2025년 12월 말에 634억원이었다.
- 연결 기준 2025년 1월부터 12월까지의 영업활동현금흐름은 1,990,445,887원이다.
- 연결 기준 2025년 12월 말의 부채비율(부채총계를 자본총계로 나눈 비율)은 60.8%이다.
- 별도 기준 수익(매출액)은 2025년 1월부터 12월까지 18,213,976,515원이었다.
- 연결 기준 영업이익(손실)은 2025년 1월부터 12월까지 -34억원이었다.
- 연결 기준 당기순이익(손실)은 2025년 1월부터 12월까지 -39억원이었다.
