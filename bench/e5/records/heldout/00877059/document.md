# 삼성바이오로직스 2025년 사업보고서 메모

삼성바이오로직스의 2025년 사업보고서에 실린 재무제표 수치를 정리했다. 금액은 원화다.

- 별도 기준 매출액은 2025년 1월부터 12월까지 4조 5,570억원이었다.
- 연결 기준 2025년 1월부터 12월까지의 영업이익률(영업이익을 매출액으로 나눈 비율)은 45.4%이다.
- 연결 기준 매출액은 2023년 1월부터 12월까지 34,971억원이었다.
- 2025년 1월부터 12월까지의 연결 기준 영업이익은 2,069,221,266,630원으로 집계됐다.
- 연결 기준 2025년 12월 말의 자산총계는 11조 607억원이다.
- 연결 기준 2025년 1월부터 12월까지의 매출액은 4조 5,570억원이다.
- 연결 기준 2025년 1월부터 12월까지의 매출액은 한 해 전 같은 기간(2024년 1월부터 12월까지)보다 30.3% 줄었다.
- 2025년 1월부터 12월까지의 연결 기준 당기순이익은 1,586,186,963,312원으로 집계됐다.
- 2024년 1월부터 12월까지의 연결 기준 영업이익은 1,321,366,380,588원으로 집계됐다.
- 2025년 1월부터 12월까지의 연결 기준 영업활동으로 인한 현금흐름은 2조 2,478억원으로 집계됐다.
- 연결 기준 매출액은 2024년 1월부터 12월까지 4조 2,621억원이었다.
- 연결 기준 2024년 12월 말의 부채총계는 6조 4,316억원이다.
