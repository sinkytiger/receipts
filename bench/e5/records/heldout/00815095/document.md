# 우리이앤엘하루틴 2025년 사업보고서 메모

우리이앤엘하루틴의 2025년 사업보고서에 실린 재무제표 수치를 정리했다. 금액은 원화다.

- 2025년 1월부터 12월까지의 연결 기준 영업이익(손실)은 69억원으로 집계됐다.
- 별도 기준 2025년 1월부터 12월까지의 수익(매출액)은 119,952,903,890원이다.
- 연결 기준 당기순이익(손실)은 2025년 1월부터 12월까지 -96,474,580원이었다.
- 연결 기준 수익(매출액)은 2024년 1월부터 12월까지 1,469억원이었다.
- 2025년 12월 말의 연결 기준 자산총계는 1,220억원으로 집계됐다.
- 2024년 1월부터 12월까지의 연결 기준 영업이익(손실)은 6,645,819,070원으로 집계됐다.
- 연결 기준 2025년 1월부터 12월까지의 영업이익률(영업이익(손실)을 수익(매출액)으로 나눈 비율)은 0.2%이다.
- 연결 기준 2025년 1월부터 12월까지의 수익(매출액)은 1,212억원이다.
- 연결 기준 부채총계는 2024년 12월 말에 307억원이었다.
- 연결 기준 2025년 1월부터 12월까지의 영업활동현금흐름은 10,132,629,159원이다.
- 연결 기준 2025년 1월부터 12월까지의 수익(매출액)은 한 해 전 같은 기간(2024년 1월부터 12월까지)보다 17.5% 늘었다.
- 2023년 1월부터 12월까지의 연결 기준 수익(매출액)은 1,420억원으로 집계됐다.
