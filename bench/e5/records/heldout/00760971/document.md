# 크래프톤 2026년 반기보고서 메모

크래프톤의 2026년 반기보고서에 실린 재무제표 수치를 정리했다. 금액은 원화다.

- 2026년 4월부터 6월까지의 별도 기준 영업수익은 8,259억원으로 집계됐다.
- 연결 기준 2026년 1월부터 6월까지의 영업수익은 2조 240억원이다.
- 2025년 12월 말의 연결 기준 부채총계는 22,495억원으로 집계됐다.
- 연결 기준 2026년 4월부터 6월까지의 영업이익은 9,725억원이다.
- 연결 기준 2026년 1월부터 6월까지의 영업이익은 9,725억원이다.
- 연결 기준 2026년 1월부터 6월까지의 영업활동으로 인한 현금흐름은 458,676,015,045원이다.
- 연결 기준 2025년 4월부터 6월까지의 영업수익은 6,620억원이다.
- 연결 기준 2026년 6월 말의 자산총계는 9,433,648,042,482원이다.
- 연결 기준 2026년 4월부터 6월까지의 반기순이익(손실)은 -299억원이다.
- 연결 기준 2026년 4월부터 6월까지의 영업수익은 한 해 전 같은 기간(2025년 4월부터 6월까지)보다 94.9% 늘었다.
- 연결 기준 2026년 4월부터 6월까지의 영업이익률(영업이익을 영업수익으로 나눈 비율)은 31.8%이다.
- 연결 기준 2026년 4월부터 6월까지의 영업수익은 12,902억원이다.
