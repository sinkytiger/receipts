# 자이에스앤디 2025년 사업보고서 메모

자이에스앤디의 2025년 사업보고서에 실린 재무제표 수치를 정리했다. 금액은 원화다.

- 연결 기준 2025년 1월부터 12월까지의 영업이익(손실)은 12,505,665,943원이다.
- 연결 기준 2025년 1월부터 12월까지의 법인세비용차감전순이익(손실)은 509억원이다.
- 연결 기준 2025년 1월부터 12월까지의 당기순이익은 371억원이다.
- 2025년 1월부터 12월까지의 별도 기준 수익(매출액)은 453,912,289,316원으로 집계됐다.
- 연결 기준 부채총계는 2024년 12월 말에 6,391억원이었다.
- 연결 기준 2025년 1월부터 12월까지의 영업이익률(영업이익(손실)을 수익(매출액)으로 나눈 비율)은 0.9%이다.
- 2025년 1월부터 12월까지의 연결 기준 수익(매출액)은 1,387,596,056,216원으로 집계됐다.
- 2024년 1월부터 12월까지의 연결 기준 수익(매출액)은 1조 1,199억원으로 집계됐다.
- 연결 기준 2025년 1월부터 12월까지의 수익(매출액)은 한 해 전 같은 기간(2024년 1월부터 12월까지)보다 71.2% 줄었다.
- 연결 기준 2023년 1월부터 12월까지의 영업이익(손실)은 1,266억원이다.
- 연결 기준 2025년 1월부터 12월까지의 영업활동현금흐름은 -25,282,431,150원이다.
- 2025년 12월 말의 연결 기준 자산총계는 1조 3,052억원으로 집계됐다.
